# Spam Detection using Machine Learning

An end-to-end NLP project built using Python, Scikit-learn, and Streamlit.

## Features

- Text Cleaning
- Tokenization
- Stopword Removal
- TF-IDF Vectorization
- Logistic Regression Classification
- Real-time Spam Prediction

## Tech Stack

- Python
- Scikit-learn
- NLTK
- Streamlit
- Joblib
